# Fotos nuevas

Coloca aquí una fotografía de un impulsor o tazón, recortada para mostrar una sola pieza. El script de Docker procesa JPG, JPEG, PNG, BMP y TIFF cuando encuentra estos archivos. Las fotos propias se leen mediante un montaje de solo lectura y se excluyen del repositorio y de la imagen Docker. La carpeta de evidencia conserva el nombre de cada archivo y su predicción.
